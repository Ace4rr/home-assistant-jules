# Интеграция Jules Agent для Home Assistant

## Концепция
Проект представляет собой нативную интеграцию агента Jules в систему умного дома Home Assistant.
Выбран "Путь А" — создание полноценной Backend-интеграции (Python), которая общается с официальным API Jules и транслирует данные в виде стандартных сущностей (Sensor) Home Assistant. Для визуализации используется пользовательская карточка (Custom Lovelace Card) на легковесном стеке (LitElement).

Такой подход позволяет:
1. Использовать статусы агента Jules в автоматизациях умного дома (например, "если агент завершил задачу, отправить уведомление на телефон").
2. Безопасно хранить API ключи на стороне сервера.
3. Обеспечить красивый и отзывчивый интерфейс через пользовательскую карточку, стилизованную под оригинальный интерфейс Jules.

## Архитектура

### 1. Backend (Python Integration)
Располагается в папке `custom_components/jules/`.

* **`manifest.json`**: Манифест интеграции, описывающий зависимости и параметры для Home Assistant и HACS.
* **`config_flow.py`**: Отвечает за удобную настройку через веб-интерфейс Home Assistant (пользователь вводит API URL и токен доступа без редактирования YAML).
* **`api.py`**: Модуль для взаимодействия с официальным REST API Jules. Осуществляет опросы (polling) данных или держит постоянное соединение (websocket), в зависимости от возможностей API.
* **`sensor.py`**: Создает сущности в HA. Например:
  * `sensor.jules_agent_status` (Состояние: Idle, Working, Error).
  * `sensor.jules_current_task` (Текст текущей выполняемой задачи).
* **`coordinator.py`**: (Паттерн DataUpdateCoordinator) Отвечает за периодическое обновление данных из API и рассылку обновлений всем зависимым сущностям.

### 2. Frontend (Lovelace Custom Card)
Располагается в папке `custom_components/jules/www/` (статика, отдаваемая браузеру).

* **`jules-agent-card.js`**: Пользовательский веб-компонент на базе `LitElement`.
  * Получает состояния сенсоров из объекта `hass` (ядро Home Assistant).
  * Отрисовывает красивый виджет с именем агента, текущим статусом, индикатором прогресса и описанием задачи.
  * Содержит заделы (плейсхолдеры) для кнопок управления (Пауза, Новая задача, Стоп), которые в будущем будут вызывать сервисы (services) Home Assistant для отправки команд на бэкенд.

## План масштабирования и добавления интерактива
1. **Текущий этап**: Реализация режима чтения (Read-Only) — получение статусов через API и отрисовка на карточке.
2. **Следующий этап**: Добавление Home Assistant Services (например, `jules.send_task`, `jules.stop_task`) в `__init__.py`.
3. **Финальный этап**: Привязка кнопок в `jules-agent-card.js` к вызовам этих сервисов для полноценного двустороннего управления агентом прямо из дашборда.
